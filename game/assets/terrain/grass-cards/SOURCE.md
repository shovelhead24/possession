Original RGBA source images are preserved. The offline showcase refinement makes
mipmapped textures and crossed, height-subdivided card meshes. Runtime shading
adds muted colour variation and the shared spatial wind field. The individual
blade atlas WheatGrass_Diffuse-WheatGrass_Opacity.png is not used. The clump-named
wheat file also contains a blade row: mesh UVs select two small groups rather
than showing the entire row on each card.
