# Altay restored — 16 October 2026

The Rebuild scene restores one Altay near the starting Warthog, trying four nearby pads and avoiding loaded object/trunk collision. If all are blocked, use F1 > Actors > Altay tank. Extra tanks support parked/drivable and patrol/drivable behavior, authored yaw/routes and the existing save/undo workflow. Up to two authored tanks stream nearby, in addition to the showcase tank. Existing saves require no migration.

E / controller Square enters or exits within 6 m. WASD or left stick/R2 drives; Circle reverses, L2 handbrakes. Hold RMB to aim with the mouse; LMB or controller R1 fires. Right stick traverses the turret. Tank yaw can turn through 360 degrees. The blue + projects cannon direction. Cannon uses direct-hit damage (default 100), 450 m ray range and a default 2.5-second cooldown. It pushes nearby heavy crates. This is the earlier cannon behavior, not a new explosive splash-damage weapon. F5 selects separate tank mobility, suspension, turret and camera settings; existing tank_wheel_tuning.cfg is read without overwriting Warthog tuning. C changes views. One restart is required; tank runtime code is outside the limited Ctrl+F6 editor reload scope.

## Model and frame budget
The original GLB has 999 nodes, 466 mesh parts and 968,227 triangles. The source asset is untouched. Cached generated LOD indices provide a reduced base of 187,202 triangles (80.7% fewer); vertices are retained, so this is not an equivalent memory reduction. Hull/turret/barrel batch separately into 2/2/1 material draws. The 124 belt links use the earlier two MultiMeshes; 24 wheel parts remain independent. Tiny track/wheel shadows are disabled; meshes and belt batches cull at 280 m. Track animation runs at 30 Hz within 60 m, 10 Hz to 200 m, and skips stationary tracks. Eight physical suspension rays remain, with the existing tyre solver.

Isolated Intel UHD Compatibility render check, 1366x768, 120 measured frames after warmup: hidden 1.724 ms mean; visible 4.364 ms, 51 draws / 525,298 submitted primitives including passes. This isolates the model on a plain background, not gameplay FPS. A real Rebuild fixed view with actors paused and isolated empty layouts measured hidden 9.187 ms, visible 9.194 ms, hidden-again 8.332 ms; draws 443 -> 484 and primitives 340,429 -> 696,679. Timing drift makes a precise incremental cost inconclusive. Neither test certifies the 120 FPS target or performance in the user's saved forest/combat scene.
