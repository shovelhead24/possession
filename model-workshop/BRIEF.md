# Possession model production

Produce original, finished, low-poly weapons and vehicles for the existing catalogue. The target is crude realism: physically plausible objects represented with an economical early-2000s mesh/material budget. Read ART_DIRECTION.md as the authoritative style and review standard. Gameplay attack reach is not physical mesh length. Avoid toy proportions, swollen guards/grips and decorative faceting. Do not copy its meshes or make every item futuristic: a spear remains a spear, a horse remains a horse, and the runabout differs clearly from the off-roader. Function and cultural/technology differences should read at gameplay distance.

All work lives here, independent of the main game's terrain and gameplay. No new mechanics or changes to the deferred 30-second loop. Export Godot-compatible GLB at metre scale, Y-up after export, with consistent forward direction documented in each README. Blender source uses Z-up. Use meaningful origins, floor contact and stable placement. Weapons need grip and applicable muzzle/ejection markers; vehicles need wheel/rotor/leg/turret pivots and seat/attachment markers where applicable. Static posing for living mounts is acceptable for this art batch, but limbs need useful separations and the missing animation must be documented.

Per asset directory: deterministic build.py, source.blend, model.glb, README.md. Reusable geometry/material helpers belong in lib/. The README records intent, dimensions, axis convention, pivots, triangle/material budget, rebuild command and remaining integration/animation needs. Scripts should work using Blender's bundled Python without downloads or third-party modules. Make any shared helpers backward-compatible and run affected builds if changing them.

Budgets are ceilings, not targets: weapons at most 4,500 triangles; vehicles/mounts at most 14,000; at most 12 materials. Prefer substantially less when the silhouette permits. Avoid high-segment cylinders, redundant internal faces, meaningless subdivisions, pure primitives passed off as finished assets, missing backs and unassigned materials. Shared palettes, bevelled profiles, purposeful negative spaces and carefully proportioned distinctive parts should provide quality at low cost.

The supervisor imports the GLB into a clean Blender scene, measures the mesh, renders two views, imports the workshop into Godot 4.5, and submits the renders for two independent visual approvals, correcting misleading README direction between revisions. Only passing assets are committed. PNG evidence is local and ignored by Git; metrics/review records are committed. A model is not gameplay-integrated just because it imports successfully.

The active queue is TASKS.md in the checkout. Runtime status lives alongside the installed worker, outside this repository. Ordinary assets use GPT-5.6-Luna; complex forms and repairs use GPT-5.6-Sol; visual approval uses Sol. Usage limits retain files and retry after 15 minutes. No token purchases, reset credits, account switching, automatic pushes or merging.
